# UMS IAM Platform

Enterprise Identity and Access Management Platform built using Spring Boot Microservices Architecture.

## Overview

UMS IAM Platform is a scalable and secure Identity and Access Management solution designed for modern organizations. The platform provides centralized authentication, authorization, user management, organization management, and notification services.

## Features

### Authentication & Security

* JWT Authentication
* Refresh Tokens
* Role Based Access Control (RBAC)
* MFA Support
* Password Reset
* Email Verification

### User Management

* User Registration
* User Profiles
* User Status Management

### Organization Management

* Create Organizations
* Organization Members
* Organization Administration

### Notification System

* Welcome Emails
* Verification Emails
* Password Reset Emails
* Event Driven Notifications

## Microservices

* API Gateway
* Discovery Service (Eureka)
* Config Service
* Auth Service
* User Service
* Organization Service
* Notification Service
* Authorization Service
* Admin Service
* Audit Service
